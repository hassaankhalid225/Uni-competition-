# Design Quality Bar

The product must look like it came from an experienced product designer, not an AI template.

## Required
- A written creative direction (`docs/project/05-ui-ux-plan.md`) before building UI: audience,
  personality (3 adjectives), type pairing, colour system, spacing scale, motion principles.
- One clear focal point per screen; hierarchy through size, weight and space before colour.
- A spacing scale (4/8-based) and a type scale used consistently.
- Real (or realistic, clearly sample) content. Write actual copy — no lorem ipsum, no
  "Revolutionize your workflow with AI-powered synergy".
- Review every key screen as a screenshot at mobile and desktop widths and iterate at least once.

## Avoid (default AI-template tells)
- Purple-to-blue gradients everywhere, glowing blobs, random glassmorphism.
- Centred-everything layouts; identical 3-column icon-card grids repeated down the page.
- Emoji as icons; mixed icon sets; more than two typefaces.
- Fake stats ("10k+ users"), fake testimonials, fake logos.
- Animations on everything; 3D objects with no connection to the product.
- Low-contrast grey-on-grey text; borders + shadows + backgrounds on the same element.

Each decorative element must answer: *what does this communicate?* If nothing — remove it.
