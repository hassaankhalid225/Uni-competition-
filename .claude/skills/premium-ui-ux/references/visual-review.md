# Visual Review Checklist

Run against real screenshots (390 / 768 / 1440 px). Score each 1–5; fix anything ≤ 3.

## Hierarchy & composition
- [ ] In 3 seconds, is it obvious what this screen is and what to do first?
- [ ] One focal point; one primary action.
- [ ] Clear grouping by proximity; consistent alignment edges.
- [ ] Section rhythm varies (marketing) / density is consistent (app).

## Typography
- [ ] ≤ 2 families, consistent scale, no orphan sizes.
- [ ] Comfortable line length and leading; headings visually distinct from body.
- [ ] Numbers tabular where compared.

## Colour & contrast
- [ ] Neutral-dominant palette; accent reserved for action/meaning.
- [ ] Text contrast passes AA; disabled states still legible.
- [ ] Semantic colours used consistently (green always success, etc.).

## Detail & craft
- [ ] Consistent radii, icon set, stroke widths, shadow style.
- [ ] No overflowing text, clipped elements, misaligned baselines, uneven gaps.
- [ ] Hover/focus/active/disabled states exist for all interactive elements.
- [ ] Images crisp and correctly cropped; no stretched assets.

## Content
- [ ] Real, specific copy; no lorem ipsum, no buzzword soup.
- [ ] No fake statistics/testimonials/logos.
- [ ] Empty/error states written for humans.

## Responsiveness
- [ ] Mobile layout is designed, not just stacked; nav usable with a thumb.
- [ ] Tables adapt (horizontal scroll container or card layout) without breaking the page.

## AI-template tells — remove on sight
Purple/blue gradient hero · glowing orbs · "✨" emojis as icons · identical 3-up icon cards
repeated · centred everything · generic "Revolutionize / Supercharge / Unlock" headlines ·
glass cards on plain backgrounds · gradient text everywhere · random floating 3D shapes ·
excessive drop shadows · every element fades-up on scroll.

## Output format
List: issue → why it hurts → concrete fix (token/class/layout change). Prioritise by visibility
in the demo.
